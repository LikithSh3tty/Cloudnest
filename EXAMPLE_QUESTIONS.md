# Example Questions

A curated set of questions for manually testing the support agent, from single-fact
lookups to questions that require combining several doc sections at once. Useful
after any change to retrieval, the prompt, or the docs themselves.

## Product Information

- What is CloudNest?
- What are the core features of CloudNest?
- Which operating systems does CloudNest support?
- Does CloudNest have a mobile app?
- What backup schedules are available?

## Billing & Pricing

- What plans does CloudNest offer?
- Compare the Free, Pro, and Team plans.
- How much does the Pro plan cost?
- Is there an annual discount?
- What happens if my payment fails?
- What happens if I downgrade my subscription?
- Can Team customers pay by bank transfer?
- Are monthly subscriptions refundable?

## Technical Setup

- How do I install the CloudNest desktop app?
- What is Selective Sync?
- Where can I configure bandwidth limits?
- How do I generate an API key?
- What is the API rate limit?
- Does CloudNest provide a CLI?
- Can I use the CLI on Linux?
- What happens if the same file is edited on two devices while offline?

## Security & Privacy

- How is my data encrypted?
- Does CloudNest support end-to-end encryption?
- Is CloudNest HIPAA compliant?
- Can Team plans use EU data residency?
- What happens if I lose my encryption key?

## Account Management

- How do I reset my password?
- How do I change my email address?
- Does CloudNest support two-factor authentication?
- How do I permanently delete my account?
- Can I recover my account after deleting it?

## Troubleshooting

- My sync is stuck. What should I do?
- Why is my sync so slow?
- What does "Storage Full" mean?
- How can I recover deleted files?
- Why does the app keep asking me to sign in?
- The desktop app won't launch. How can I fix it?

## Multi-Document Reasoning

These require combining information from more than one doc section.

- Which plans include API access, and how much do they cost?
- I need API access and support for five devices. Which plan should I choose?
- My storage is full and syncing has stopped. What should I do?
- I accidentally deleted a file yesterday. Can I still recover it?
- I signed in using Google and forgot my password. What should I do?
- Which plans support API access, and what storage do they provide?
- I need API access, Linux support, and 500 GB of storage. Which plan is right for me?
- I need unlimited devices, EU data residency, and API access. Which plan should I choose?
- I'm using 600 GB of storage and my payment failed three times. What happens to my account?
- What security features protect my files during upload, storage, and sharing?

## Complex Scenarios

These combine several constraints into one realistic customer request.

- I'm a Linux developer with 12 employees. We need API access, EU data residency, bank transfer payments, CLI automation, and unlimited devices. Which plan should we choose, and why?
- I'm moving from the Free plan to Team. Explain every feature I'll gain, every billing change, every security improvement, and every developer capability available after upgrading.
- Compare the Free, Pro, and Team plans in terms of storage, devices, pricing, API access, billing, and payment methods.
- Explain the complete lifecycle of a deleted file, from deletion, to Trash recovery, to permanent account deletion.
- What's the cheapest way to get API access while supporting five devices?
- My sync stopped because my storage is full. Will emptying the Trash fix it, or should I upgrade?
- I accidentally edited the same file on two devices while offline. What happens when they sync again?
